氟化工生产技术知识库 — 给同事

你这边已经有三册教材的话，不用再找 PDF。本压缩包里带的是程序、已抽取的教材文本和向量索引。

一、先装 Python（只需一次）
  https://www.python.org/downloads/
  安装时务必勾选 Add Python to PATH。建议 3.10 或更高。

二、解压后双击「启动知识库.bat」
  第一次会自动建虚拟环境并装依赖（需要能访问互联网）。
  装好后浏览器会打开问答页。关掉那个黑窗口即停止服务。

三、怎么用
  - 不填 API Key：勾选「仅检索原文」，直接看教材相关段落。
  - 要流畅回答：在左侧填 DeepSeek 等 API Key（Key 只存在你自己电脑的浏览器里）。
  - 要加厂内规程、会议纪要等：左侧「随时补充资料」粘贴或上传 txt/md/pdf，会立刻更新知识库。

四、可选
  若要把自己的 PDF 也放进这个文件夹，以后才能在本机重新 OCR；日常问答不需要 PDF。
